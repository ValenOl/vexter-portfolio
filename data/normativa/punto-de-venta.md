El punto de venta es un número (ej. "0001") que identifica desde dónde
se emite un comprobante, pensalo como una "sucursal" numerada, aunque
sea un monotributista con un solo lugar de trabajo (o ninguno, si
trabaja de forma remota).

Cada comprobante lleva el número de punto de venta + un número
correlativo propio de ESE punto de venta (ej. factura C 0001-00000042).
Los números correlativos no se comparten entre puntos de venta distintos.

**Cuándo hace falta más de uno**: si el monotributista factura desde
distintos sistemas (ej. facturador web de ARCA para algunas operaciones,
y un sistema propio o de terceros, como Vexter, para otras), cada
sistema necesita su propio punto de venta habilitado, para no pisar
numeración entre uno y otro.

Se gestiona (alta de un punto de venta nuevo) desde el portal de
Comprobantes en Línea o el administrador de puntos de venta de ARCA.
